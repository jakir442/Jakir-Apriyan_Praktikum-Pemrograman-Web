## 🧐 Tentang Repositori

Repositori **Praktikum-Pemrograman-Web** dibuat sebagai wadah pengarsipan seluruh aktivitas praktikum mata kuliah **Pemrograman Web**. Repositori ini mencakup implementasi dasar web development (HTML, CSS, JavaScript) hingga penggunaan kerangka kerja (*framework*) modern dan pemrograman *side-server* (PHP / Node.js / Database).

## 🚀 Cara Menjalankan Project

Ikuti langkah-langkah berikut untuk menjalankan proyek di komputer lokal Anda:

### Prerequisites
1. Web Server lokal seperti **XAMPP**, **WAMP**, atau **Laragon**.
2. **Web Browser** modern (Chrome, Firefox, Edge, dll).
3. **Git** terinstall di komputer.

### Langkah-Langkah

1. **Clone Repositori**
   ```bash
   git clone https://github.com/Jakir-Apriyan/Praktikum-Pemrograman-Web.git
   ```

2. **Pindahkan Direktori Proyek**
   Pindahkan folder hasil clone ke dalam direktori server lokal Anda (contoh: `htdocs` jika menggunakan XAMPP).
   ```bash
   # Jalankan di XAMPP htdocs
   cd C:/xampp/htdocs/Praktikum-Pemrograman-Web
   ```

3. **Import Database (Jika Diperlukan)**
   - Buka phpMyAdmin di browser (`http://localhost/phpmyadmin`).
   - Buat database baru.
   - Import file `.sql` yang tersedia pada folder modul terkait (misal: `Modul-05-CRUD-MySQL/database.sql`).

4. **Jalankan Aplikasi**
   Buka browser dan akses alamat berikut:
   ```text
   http://localhost/Praktikum-Pemrograman-Web/
   ```
