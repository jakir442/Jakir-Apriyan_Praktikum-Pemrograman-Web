## 🛠️ Langkah 4: Membuat File Dokumentasi Repositori

Prosedur inisialisasi awal repositori pada environment lokal:

1. Buka **Visual Studio Code**.
2. Klik **Open Folder** dan buat folder baru misalnya `praktikum-web2026`, lalu klik **Select Folder**.
3. Buat file bernama `README.md` di folder utama proyek.
4. Tuliskan identitas serta catatan praktikum.

## 🚀 Cara Menjalankan Project

1. **Clone Repositori:**

    ```bash
    git clone https://github.com/Jakir-Apriyan/Jakir-Apriyan_Praktikum-Pemrograman-Web.git
    ```

2. **Buka Folder di VS Code:**

    ```bash
    cd Jakir-Apriyan_Praktikum-Pemrograman-Web
    code .
    ```

3. **Jalankan Local Web Server:**
    - Buka **Laragon**, pastikan service **Apache** dan **MySQL** (Port 3306) dalam posisi _Started_.
    - Akses halaman web melalui browser di `http://localhost/praktikum-web2026`.
